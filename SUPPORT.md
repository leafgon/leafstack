# Support

## Usage questions

For reproducible questions about these public skills and scripts, open a GitHub
issue and include:

- operating system and Node.js version;
- the command that failed;
- the target route family, with graph identity anonymized when necessary;
- expected and observed behavior; and
- redacted error codes or correlation IDs.

Never include tokens, cookies, authorization headers, runtime file references,
payload base64, private graph data, or provider credentials.

## Bugs and feature requests

Use the repository issue templates. A focused reproduction or minimal graph
fixture is welcome when it contains no sensitive data.

## Security issues

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md), not
through a public support issue.

## Service and account support

This repository does not provide an availability SLA or account-administration
support. For Leafgon account, billing, permission, or hosted-service incidents,
use the support channel provided with your Leafgon account.
